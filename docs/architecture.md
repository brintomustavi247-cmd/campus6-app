# Architecture

RankPush is an SPA using React 19 + Vite.
It communicates with Firebase via standard Web SDKs.

- `src/components/`: Reusable UI elements (buttons, cards, inputs).
- `src/views/`: Page-level components.
- `src/types/`: TypeScript interfaces and gamification rules.
- `src/utils/`: Gamification calculation utilities.
